## 5. Day 1 controlled objectives to preserve

The existing Foundation materials establish Day 1 as baseline state observation and introductory coherence/attention control. The reconstruction must preserve the intended capabilities unless source evidence requires a controlled correction:

- observe the starting mental, emotional, and bodily state;
- reduce unnecessary physical tension;
- deliberately generate a coherent or appreciative state;
- notice attention capture and return;
- experience the distinction between narrow attention and broad spatial/open awareness;
- carry at least one trained state into daily activity;
- record raw experience before interpretation.

These objectives are curriculum constraints, not proof that the current script uses the correct source method.

### 6.2 Build the source evidence packet

For every candidate source, record:

- teacher or organization;
- exact public work or authorized source;
- URL, title, date, and timestamps/sections;
- target state;
- posture;
- breathing method;
- attentional method;

- sequence and transition;
- sound/binaural use;
- markers and corrections;
- return method;
- limitations and unresolved details;
- source/publication class.

### 6.3 Build the Day 1 segment crosswalk

Required fields:

`TIMELINE SEGMENT | COURSE OBJECTIVE | PRIMARY SOURCE | SOURCE OPERATION | SOURCE EVIDENCE | QCTP PARAPHRASE | QCTP ENHANCEMENT | FIDELITY STATUS`

No segment may remain source-blank when the script advances to rendering.

### 6.4 Resolve method compatibility

When more than one teacher contributes:

- compare their state targets and assumptions;
- preserve source-specific terminology;
- identify incompatible breathing, imagery, or attention instructions;
- avoid stacking methods merely because time is available;
- use one primary source baseline per segment;
- label transitions as `QCTP_SYNTHESIS`;
- move nonessential methods to later Foundation days or parallel source tracks.

### 6.5 Produce the source-faithful baseline

Create an original QCTP paraphrase that follows the verified source method without the QCTP enhancement layer. This establishes what must be preserved.

### 6.6 Produce the enhancement delta

Separately define improvements such as:

- exact clarification of vague actions;
- additional coaching where the source assumes prior knowledge;
- slower voice delivery;
- continuous support audio;
- source-compatible binaural or ambient treatment;
- pre-cue marker and fades;
- local/offline packaging;
- troubleshooting and safe alternatives;
- readiness and output checks;
- return pacing;
- voice-first debrief and state markers.

Every enhancement must state why it does not alter the source method.

### 6.7 Lock the source-labeled script

Each spoken segment must include:

- cue ID and timestamp;
- exact original QCTP wording;
- primary source ID;
- source-operation ID;
- enhancement IDs;
- source-faithful/synthesis/original classification;
- transcript hash;
- target delivery rate;
- maximum duration;
- audio support mode;
- return and safety status.

Only this source-labeled script may proceed to voice rendering.
