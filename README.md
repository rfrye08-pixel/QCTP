# QCTP

Mobile-first Progressive Web App for the controlled 112-day Quantum Consciousness Training Program.

## Rev 1.1 release scope

- Fully authored Day 1 lesson and exact 25-minute guided practice
- Spoken cue timeline with real silence intervals
- Guided, Light Guidance, and Minimal modes
- 90-second accelerated sequencer verification
- Local workbook, progress state, structured exploration logs, and JSON export/import
- PWA installation and offline shell
- System-voice playback with screen wake-lock request where supported

Days 2–112 are represented in the controlled curriculum structure but are intentionally not fabricated in this release.
